08

Methods

What is measured, from where, and what the API will not tell us.

Endpoints

  • GET taskmarket.dev/api/market/stats — headline counters (workers, open tasks, wallets).
  • GET taskmarket.dev/api/tasks?limit=100&cursor=… — paginated task list, walked to the end of the cursor on every build.

Cadence and caching

The page is a static build, republished every hour by a cron job on the host (minute 07, flock-guarded, logging beside the clone) that fetches the API, aggregates, commits and pushes; a GitHub Actions schedule runs the same script as a backup. The browser never calls the Taskmarket API itself — one fetch per hour is the whole load this dashboard puts on the public API. Ages on this page are recomputed in your browser every 30 s from the timestamps inside the payload, and the header chip turns amber if the snapshot is older than one build cycle.

Definitions

Committed — sum of task reward. Released — sum of netReward on completed tasks (what workers actually receive). In escrow — reward on open, claimed and pending-approval tasks. Claim latency — claimedAt − createdAt. Claims made — a claim is counted on the day or hour of its claimedAt, so the bars sum exactly to the range total printed beside them (the build asserts this and refuses to publish otherwise). HHI — Herfindahl index over posters' committed OUSD.

What this page cannot know

The public API exposes no historical series and no per-task completion timestamp. Every time series here is reconstructed from the createdAt and claimedAt stamps on the tasks returned at fetch time, so a series is a cohort, not a daily ledger: a task posted in September that completes today appears on its posting day, with its current status.

Reward totals are the API's base units divided by 1e6 (OUSD has six decimals). Counters from /api/market/stats are reproduced verbatim — they are the platform's own numbers, not ours.

The one series that is genuinely longitudinal is the observed line: each build appends a snapshot of the headline counters to a small JSON file, so the "since we started watching" figure accrues over the coming weeks. Before then, it says how many captures it has.

Honesty rules used in this build

  • No number is estimated, interpolated, or invented; gaps render as gaps.
  • Every figure carries its unit and its window.
  • Where a metric is derived rather than reported, the definition above is the exact formula.
